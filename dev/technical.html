⚛️
Frontend (Web)

Server-side rendering = SEO. Each entity page (airtel.bhadaas.in) needs to rank on Google. React ecosystem. TypeScript for safety.
Tailwind CSS React Query Zustand React Hook Form

Mobile App
React Native (or Flutter)

Team: 1 Mobile Dev (₹80K–1.5L/month)
📅 v2 — Months 6–12
⚙️
Backend API
Node.js (Express/Fastify) OR Go
Node.js for full-stack JS team. Go for high throughput (upvotes/notifications — hundreds per second). Start Node.js, migrate hot paths to Go at scale.
Express / Fastify Prisma ORM Zod Validation JWT
Team: 1–2 Backend Devs (₹1.5–2.5L/month)
🗄️
Database
PostgreSQL (primary) + Redis (cache/queues)
Relational data (users, posts, entities) needs ACID. Redis for: Me Too count caching, notification queues, rate limiting, session storage.

Full-text search across 50K+ posts, entity name autocomplete, tag search. PostgreSQL full-text is not enough at scale. Meilisearch is simpler and cheaper for Phase 1.
Meilisearch Elasticsearch Autocomplete
Note: Meilisearch Phase 1 → Elasticsearch Phase 2
⚡ Elasticsearch in Phase 2

EC2/ECS RDS PostgreSQL ElastiCache S3 CloudFront SES Lambda Route53

Security: OWASP Top 10 Compliance

⚠️ A consumer grievance platform is a HIGH-VALUE target for: disgruntled companies trying to remove posts, fake review campaigns, doxxing attacks, and government data requests. Security is non-negotiable.
A01 — Broken Access Control

Access Control

JWT auth with short expiry (15min access, 7d refresh). Role-based (user/company/admin). Posts always show without author identity. Admin actions require 2FA.

A02 — Cryptographic Failures

Cryptographic Failures

AES-256 for PII at rest (phone, email). bcrypt for passwords. TLS 1.3 only. No sensitive data in logs. No PII in URLs or error messages.

A03 — Injection

Injection Prevention

Parameterized queries only (never raw SQL). ORM (Prisma/TypeORM). Input sanitization. HTML entity encoding for post content display.

A04 — Insecure Design

Secure Design

Phone OTP mandatory (no password-only accounts). Rate limiting on OTP (3 attempts/hour). Poster identity NEVER included in API response. Separate stores for PII vs content.

A05 — Security Misconfiguration

Hardened Config

No default credentials. All S3 buckets private. Security headers (CSP, HSTS, X-Frame-Options). No debug mode in production. Secrets in AWS Secrets Manager — never in .env files.

A06 — Vulnerable Components

Dependency Security

Dependabot for dependency updates. Regular npm audit. Docker base images from official sources. Monthly security scan with Snyk.

A07 — Auth & Session Failures

Auth Hardening

OTP-based auth only. JWT stored in httpOnly cookies (not localStorage). CSRF protection. Brute-force lockout: 5 OTP failures = 1h lockout.

A08 — Software & Data Integrity

Data Integrity

Signed deploys (GitHub Actions with signing). Integrity checks on file uploads. Virus scan on uploaded documents (ClamAV). Content hash verification.

A09 — Security Logging & Monitoring

Security Monitoring

All legal requests logged with timestamps. All moderation actions logged with admin ID. All auth events logged. CloudWatch alerts for anomalous patterns. Sentry for error tracking.

A10 — SSRF

SSRF Prevention

URL validation for external links. No server-side URL fetching from user input. Whitelist for allowed external domains.
