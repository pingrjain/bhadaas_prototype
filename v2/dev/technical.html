dev reference / technical architecture

🔧 technical architecture

complete technical stack, data models, api design, security measures, infrastructure costs, and development roadmap for bhadaas.com v2.

stack

recommended stack

battle-tested technologies chosen for scalability, developer experience, and cost efficiency.

⚛️

frontend

next.js (react)

component-based architecture, server-side rendering for seo, built-in api routes for backend logic. the modern standard for production react apps.

🐘

database

postgresql

relational database with native json support and full-text search. handles complex queries, referential integrity, and scales well with read replicas.

⚡

cache

redis

in-memory data store for session management, rate limiting, and response caching. sub-millisecond reads for hot data paths.

☁️

cloud

aws

ec2 for compute, rds for managed postgres, s3 for media storage, cloudfront for cdn, ses for transactional email. pay-as-you-grow pricing.

endpoints

api design

restful api endpoints — organized by resource. all responses in json. auth via jwt bearer tokens.

🔐 auth

post /api/auth/register register new user
post /api/auth/login login user
post /api/auth/verify verify email

📝 posts

get /api/posts list posts (with filters)
get /api/posts/:id get single post
post /api/posts create post auth required
put /api/posts/:id update post auth required
delete /api/posts/:id delete post admin only

🏢 entities

get /api/entities list entities
get /api/entities/:id get entity with posts
post /api/entities/:id/claim claim entity company only

😤 reactions

post /api/posts/:id/react add reaction auth required
delete /api/posts/:id/react remove reaction auth required

🚩 reports

post /api/posts/:id/report report post
security

security measures

platform security architecture — protecting user data, preventing abuse, and ensuring legal compliance.

🔒

end-to-end encryption

all sensitive data encrypted at rest and in transit. tls 1.3 for all connections, aes-256 for stored credentials and pii.

🛡️

no pii in public apis

public-facing api endpoints never expose personally identifiable information. user data is anonymized in all external responses.

⏱️

rate limiting

100 requests/min for anonymous users, 300 requests/min for authenticated users. redis-backed sliding window counters.

🤖

captcha protection

captcha verification on registration and posting flows. prevents bot spam and automated abuse of the platform.

📋

ip logging

ip addresses logged and hashed for law enforcement compliance. retained for 90 days per legal requirements.

🧹

input sanitization

all user inputs sanitized against xss, sql injection, and other injection attacks. parameterized queries and html escaping throughout.
